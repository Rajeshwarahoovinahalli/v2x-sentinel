# v2x-sentinel
V2X Sentinel — Secure V2X Gateway with FOTA for Autonomous Vehicle Fleets. Raspberry Pi + STM32 system with HMAC-authenticated firmware updates over UART/CAN/cloud-WiFi, a fail-safe dual-bank bootloader with power-failure rollback, replay-attack defense, and proactive V2I/V2V accident alerting. 100% verified recovery across all transports.
